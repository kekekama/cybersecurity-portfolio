# RAM BASICS

## What is
RAM (Random Access Memory) is the computer's main memory.
It has data and instructions, it is volatile(if you turn off pc, you lost the contents) and very fast.

## Cells, bits, bytes, addresses
Memory is composed of cells;
every cell has an address;
inside the cells there are bits
8 bits = 1 byte

## Difference between memory and registers
- RAM = bigger but small storage
- Registers = small memory inside the CPU, faster

## Bus
- data bus = carries the data
- address bus = carries the addresses
- control bus = carries control signals

## Difference beetween RAM/Disk

- RAM = fast, temporary
- SSD/HDD = slower, permanent

## Stack and Heap

- Stack = memory used for function calls and local variables
- Heap = memory used for dynamic memory

## Virtual Memory

The programs use virtual addresses;
the OS translates into physical addresses;
this translation is done trough pages to frames.
If a page is not in RAM, a page fault could occur.
