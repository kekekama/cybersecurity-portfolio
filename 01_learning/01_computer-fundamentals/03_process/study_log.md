Anyway a programm is an group fo instructions storage on your disk-
The process is that programm while is being executed.
Example: Chrome is the programm, if you open Chrome the OS create the Chrome process.
Inside a process there are the instruction codes, data, variables, stack, heap, the actual value of CPU registers, the point of the programm that reach, the open resources like file and connection.

If you open more times a programm, you create more different process.

A process could be in different mood
-running = it is using the cpu and executing instructions
-ready = it could starts, but the cpu isn't available
-waiting = it couldnt continue even tough th ram is available

ready-->running-->waiting
