Anyway a program is an group fo instructions storage on your disk-
The process is that program while is being executed.
Example: Chrome is the program, if you open Chrome the OS create the Chrome process.
Inside a process there are the instruction codes, data, variables, stack, heap, the actual value of CPU registers, the point of the program that reach, the open resources like file and connection.

If you open more times a program, you create more different process.

A process could be in different mood
-running = it is using the cpu and executing instructions
-ready = it could starts, but the cpu isn't available
-waiting = it couldnt continue even tough th ram is available

### Topics studied

-Thread

### What I learned

Okay a thread is a single sequence of instructions inside the process.
The threads use the resources of process to execute the instructions.
A simple program has a principle thread, a complex program multiples.
It is better to have multiples threads than multiples process because they easily share memories and resources.

Different threads share codes, global variables, heap, open files, the resources of process.
Every thread has own stack, own CPU registers, own program counter.
